🔔 Notiser i appen

Få morgonens köp, sälj och depåvärde som notis direkt från appen.

  1. Tryck Kopiera notis-kod.
  2. Öppna GitHub → New secret.
  3. Name: WEB_PUSH · Secret: klistra in koden · Add secret.

Koden är bara till för GitHub, så dela den inte med någon annan. Den ger bara rätt att skicka notiser till den här appen.
